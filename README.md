## Measurement and Characterization of Granulation Patterns in the IAG Solar Flux Spectrum

Final project for the Physics program of the Universidad de los Andes related to the 2025-2 semester. 

$\textbf{Author:}$ Claudia Alejandra Cuellar Nieto.

$\textbf{Advisor:}$ Benjamin Oostra Vannoppen.

$\textbf{Abstract:}$ This project presents a characterization of convective blueshift and the anomalous chromodependence, following the foundational work of David Gray, across the three signatures of convection: Line broadening, line asymmetry, and the line-depth dependence of convective blueshift. 
A primary outcome is a refined, blend-free list of Fe I spectral lines, providing a community resource with measured convective blueshifts, line core curvatures, line bisector slopes and excitation potentials. 
Our analysis statistically validates a $\mathring{A}$ window around the line core as optimal for analysis, confirming the methodology of Allende and Garcia.

Furthermore, we establish color dependent standard granulation curves across the entire solar spectrum, confirming that deeper lines are found at shorter wavelengths. 
Specifically, we identify an anomalous chromodependence where, for a fixed line depth, shorter-wavelength lines exhibit greater convective blueshifts, higher core bisector slopes, and narrower profiles. 
We discarded solar rotation as the cause for this phenomenon, as this anomaly is more pronounced in the disk-center spectrum where solar rotation is negilible. 
This work provides a foundational dataset and suggests the development of an adaptive algorithm for future solar spectroscopic studies.

All data and code have been uploaded in the current repository, allowing anyone interested to reproduce and verify the authenticity of the results presented.
